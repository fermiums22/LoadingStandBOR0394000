# LoadingStandBOR0394000

Контроллер нагрузочного стенда для управления магнитопорошковым тормозом на базе STM32G071RB.

* MCU: STM32G071RB
* Board: NUCLEO-G071RB
* IDE: STM32CubeIDE
* Configurator: STM32CubeMX
* Language: C

---

# System requirements

## Hardware

* NUCLEO-G071RB
* Силовая плата BDC-0320-Powerboard 33
* Магнитопорошковый тормоз SKISIA PB-5
* USB кабель для ST-Link
* ПК с STM32CubeIDE

## Software

* STM32CubeIDE
* STM32CubeMX
* ST-Link Utility (опционально)
* Терминал UART (Putty, TeraTerm, RealTerm и т.д.)

---

# Описание проекта

Проект предназначен для управления магнитопорошковым тормозом нагрузочного стенда.

Основной режим работы — регулирование тока тормоза по обратной связи от датчика тока ACS722.

Пользователь задает требуемый ток через UART-консоль, после чего PI-регулятор автоматически подбирает коэффициент заполнения ШИМ для поддержания заданного значения.

Частота контура регулирования составляет 10 кГц.

---

# Основные возможности

* Регулирование тока тормоза
* Ручное управление PWM
* PI-регулятор
* Настройка коэффициентов PI через терминал
* Калибровка нуля датчика тока
* Потоковая телеметрия
* Ограничение максимального тока
* Ограничение максимального PWM
* Самодиагностика ADC через VREFINT
* UART-консоль с историей команд

# Тактирование

Контроллер использует внешний кварцевый резонатор.

## Источник тактирования

```
HSE = 8 MHz

```

Подключение:

| Вывод | Назначение  |
| ----- | ----------- |
| PF0   | RCC_OSC_IN  |
| PF1   | RCC_OSC_OUT |

Параметры PLL:

| Параметр   | Значение |
| ---------- | -------- |
| PLL Source | HSE      |
| PLLM       | 1        |
| PLLN       | 16       |
| PLLR       | 2        |

Расчет:

```text
8 MHz × 16 / 2 = 64 MHz

```

Итоговые частоты:

| Clock  | Value  |
| ------ | ------ |
| SYSCLK | 64 MHz |
| HCLK   | 64 MHz |
| PCLK   | 64 MHz |

# Подключение контроллера

Контроллер выполнен на базе платы NUCLEO-G071RB.

Связь с силовой платой осуществляется двумя основными сигналами:

| Сигнал | Вывод STM32 | Назначение                  |
| ------ | ----------- | --------------------------- |
| CUR    | PA0         | Измерение тока              |
| PWM    | PA1         | Управление силовым каскадом |
| TX     | PA2         | UART TX                     |
| RX     | PA3         | UART RX                     |
| SWDIO  | PA13        | Отладка                     |
| SWCLK  | PA14        | Отладка                     |
| GND    | GND         | Общий провод                |

---

## Сигнал CUR

CUR подключен к выходу датчика тока ACS722.

Цепочка сигнала:

```
Тормоз
   │
   ▼
ACS722
   │
   ▼
CUR
   │
   ▼
PA0 (ADC1)

```

---

## Сигнал PWM

PWM формируется таймером TIM2.

Цепочка сигнала:

```
TIM2
  │
  ▼
PA1
  │
  ▼
PWM
  │
  ▼
UCC23313
  │
  ▼
MOSFET
  │
  ▼
Тормоз

```

# Режимы работы

## Current Control Mode

Основной режим работы.

Пользователь задает требуемый ток:

```
set <mA>

```

После этого PI-регулятор автоматически поддерживает заданное значение тока.

---

## PWM Mode

Ручное управление PWM.

```
pwm <0..100>

```

В этом режиме регулятор отключается.

---

# PI-регулятор

Частота регулирования:

```
10 kHz

```

Настраиваемые параметры:

```
Kp
Ki
Kd

```

Изменение коэффициентов возможно во время работы через терминал.

---

# Консоль управления

Параметры подключения:

```
USART2
921600 baud
8N1

```

После подключения отображается:

```
===================================
  BORK Loading Stand BOR0394000
  PI current control @ 10 kHz
===================================

Type 'help'.

```

| --------------- | ----------------- |

# Формат телеметрии

```
DATA,<tick_ms>,<set_mA>,<I_mA>,<duty%>

```

Пример:

```
DATA,100,500,498,31
DATA,200,500,501,32
DATA,300,500,500,32

```

# Команда status

Команда отображает:

* текущий режим работы;
* заданный ток;
* измеренный ток;
* коэффициент заполнения PWM;
* коэффициенты PI-регулятора;
* ограничения безопасности.

---

# Калибровка

Команда:

```
cal

```

выполняет повторную калибровку нуля датчика тока ACS722.

Рекомендуется выполнять после включения питания и при отсутствии тока через тормоз.

# Сборка проекта

2. Открыть файл `LoadingStandBOR0394000.ioc`.
3. При необходимости выполнить Generate Code.
4. Выполнить Build Project.
5. Прошить устройство через ST-Link.
