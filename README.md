# LoadingStandBOR0394000

Контроллер нагрузочного стенда для управления магнитопорошковым тормозом на базе STM32G071RB.

* MCU: STM32G071RB
* Board: NUCLEO-G071RB
* IDE: STM32CubeIDE
* Configurator: STM32CubeMX
* Language: C

---

# System requirements

## Hardware

* NUCLEO-G071RB
* Силовая плата BDC-0320-Powerboard 33
* Магнитопорошковый тормоз SKISIA PB-5
* USB кабель для ST-Link
* ПК с STM32CubeIDE

## Software

* STM32CubeIDE
* STM32CubeMX
* ST-Link Utility (опционально)
* Терминал UART (Putty, TeraTerm, RealTerm и т.д.)

# Описание проекта

Проект предназначен для управления магнитопорошковым тормозом нагрузочного стенда.

Основной режим работы — регулирование тока тормоза по обратной связи от датчика тока ACS724.

Пользователь задает требуемый ток через UART-консоль, после чего PI-регулятор автоматически подбирает коэффициент заполнения ШИМ для поддержания заданного значения.

Частота контура регулирования составляет 10 кГц.

# Архитектура системы

Силовая часть включена низковольтным ключом по минусу. Датчик тока стоит в
силовой цепи последовательно с катушкой, поэтому он измеряет реальный ток всей
петли: длинные провода, катушка и сам датчик находятся внутри одного
непрерывного токового контура.

```text
+24V ──[провод]── Катушка ──[провод]── Датчик тока ── Y ──[MOSFET]── GND
  ▲                                                        │
  └────────────────────── D_fw (Y -> +24V) ────────────────┘
```

```text
Уставка тока
      │
      ▼
PI-регулятор 10 кГц
      │
      ▼
TIM2 PWM
      │
      ├── PA5 -> UCC23313 -> MOSFET
      │
      └── PA1 -> зеркало PWM для осциллографа
                         │
                         ▼
+24V -> провода -> PB-5 -> провода -> ACS724 -> MOSFET -> GND
                         │
                         ▼
                    PA0 / ADC
                         │
                         └── обратная связь по току
```

Особенности силовой петли:

* Провода, катушка и датчик несут один и тот же непрерывный ток; провода тихие,
  датчик читает ток непрерывно.
* Энергия катушки возвращается через длинные провода и диод свободного хода
  `D_fw` в точку `+24V`. Из-за индуктивности проводов возможны пики на
  транзисторе, поэтому нужен аккуратный силовой монтаж и снаббер/ограничение
  перенапряжения при необходимости.

# Тактирование

Контроллер использует внешний кварцевый резонатор ABM3-8.000MHZ-D2Y-T,
запаянный на NUCLEO-G071RB.

MCO от ST-Link отключен. Это сделано специально: при коммутации силового
транзистора помехи раньше могли приводить к отваливанию ST-Link, а локальный HSE
кварц на плате Nucleo делает тактирование независимым от ST-Link.

## Источник тактирования

```
HSE = 8 MHz

```

Подключение:

| Вывод | Назначение  |
| ----- | ----------- |
| PF0   | RCC_OSC_IN  |
| PF1   | RCC_OSC_OUT |

Параметры PLL:

| Параметр   | Значение |
| ---------- | -------- |
| PLL Source | HSE      |
| PLLM       | 1        |
| PLLN       | 16       |
| PLLR       | 2        |

Расчет:

```text
8 MHz × 16 / 2 = 64 MHz

```

Итоговые частоты:

| Clock  | Value  |
| ------ | ------ |
| SYSCLK | 64 MHz |
| HCLK   | 64 MHz |
| PCLK   | 64 MHz |

# Подключение контроллера

Контроллер выполнен на базе платы NUCLEO-G071RB.

Питание Nucleo берется с силовой платы: на плате NUCLEO-G071RB установлена
перемычка питания `VIN`, на `VIN` приходит `+12V` с силовой платы. USB/ST-Link
используется для прошивки и отладки, но не является основным источником питания
контроллера в рабочем стенде.

Связь с силовой платой:

| Сигнал | Вывод STM32 | Назначение                  |
| ------ | ----------- | --------------------------- |
| CUR    | PA0         | Измерение тока ACS724       |
| PWM    | PA5         | Управление силовым каскадом |
| PWM_MON| PA1         | Зеркало PWM для осциллографа|
| USART2_TX | PA2      | ST-Link VCP / отладочная консоль TX |
| USART2_RX | PA3      | ST-Link VCP / отладочная консоль RX |
| USART1_TX | PC4      | Задел под Raspberry Pi TX   |
| USART1_RX | PC5      | Задел под Raspberry Pi RX   |
| SWDIO  | PA13        | Отладка                     |
| SWCLK  | PA14        | Отладка                     |
| +12V   | VIN         | Питание Nucleo от силовой платы |
| GND    | GND         | Общий провод                |

---

## Сигнал CUR

CUR подключен к выходу датчика тока ACS724.

Цепочка сигнала:

```
+24V -> провода -> PB-5 -> провода -> ACS724 -> MOSFET -> GND
                                │
                                ▼
                              CUR
                                │
                                ▼
                            PA0 (ADC1)

```

---

## Сигнал PWM

PWM формируется таймером TIM2.

Цепочка сигнала:

```
TIM2
  │
  ▼
PA5
  │
  ▼
PWM
  │
  ▼
UCC23313
  │
  ▼
MOSFET
  │
  ▼
нижний ключ силовой цепи

PA1 используется как PWM_MON — дублирующий сигнал для осциллографа.

```

# Режимы работы

Основной режим работы.

# Консоль управления

В проекте включены два UART-порта. Это сделано с заделом под подключение
Raspberry Pi: можно оставить ST-Link VCP для отладки с ПК и параллельно
подключить внешний управляющий контроллер к USART1.

Оба порта работают как одна общая консоль управления:

* команды принимаются с обоих UART;
* ответы, логи и сообщения кнопки зеркалятся на оба UART;
* потоковая телеметрия и история команд ведутся независимо для каждого порта.

Параметры подключения:

```
921600 baud
8N1

```

| Порт   | Выводы STM32 | Назначение |
| ------ | ------------ | ---------- |
| USART2 | PA2 / PA3    | ST-Link VCP, терминал на ПК |
| USART1 | PC4 / PC5    | Задел под Raspberry Pi или внешний контроллер |

После подключения отображается:

```
===================================
  BORK Loading Stand BOR0394000
  PI current control @ 10 kHz
===================================

Type 'help'.

```

# Калибровка

Команда:

```
cal

```

выполняет повторную калибровку нуля датчика тока ACS724.

Рекомендуется выполнять после включения питания и при отсутствии тока через тормоз.

3. При необходимости выполнить Generate Code.
4. Выполнить Build Project.
5. Прошить устройство через ST-Link.
