# LoadingStandBOR0394000

Контроллер нагрузочного стенда для управления магнитопорошковым тормозом на базе STM32G071RB.

* MCU: STM32G071RB
* Board: NUCLEO-G071RB
* IDE: STM32CubeIDE
* Configurator: STM32CubeMX
* Language: C

# Описание проекта

Проект предназначен для управления магнитопорошковым тормозом нагрузочного стенда.

Основной режим работы — регулирование тока тормоза по обратной связи от датчика тока ACS724.

Пользователь задает требуемый ток через UART-консоль, после чего PI-регулятор автоматически подбирает коэффициент заполнения ШИМ для поддержания заданного значения.

Частота контура регулирования составляет 10 кГц.

# Архитектура системы

Силовая часть включена низковольтным ключом по минусу. Датчик тока стоит в
силовой цепи последовательно с катушкой, поэтому он измеряет реальный ток всей
петли: длинные провода, катушка и сам датчик находятся внутри одного
непрерывного токового контура.

```text
+24V ──[провод]── Катушка ──[провод]── Датчик тока ── Y ──[MOSFET]── GND
  ▲                                                        │
  └────────────────────── D_fw (Y -> +24V) ────────────────┘
```

```text
Уставка тока
      │
      ▼
PI-регулятор 10 кГц
      │
      ▼
TIM2 PWM
      │
      ├── PA5 -> UCC23313 -> MOSFET
      │
      └── PA1 -> зеркало PWM для осциллографа
                         │
                         ▼
+24V -> провода -> PB-5 -> провода -> ACS724 -> MOSFET -> GND
                         │
                         ▼
                    PA0 / ADC
                         │
                         └── обратная связь по току
```

Особенности силовой петли:

* Провода, катушка и датчик несут один и тот же непрерывный ток; провода тихие,
  датчик читает ток непрерывно.
* Энергия катушки возвращается через длинные провода и диод свободного хода
  `D_fw` в точку `+24V`. Из-за индуктивности проводов возможны пики на
  транзисторе, поэтому нужен аккуратный силовой монтаж и снаббер/ограничение
  перенапряжения при необходимости.

# Тактирование

Контроллер использует внешний кварцевый резонатор ABM3-8.000MHZ-D2Y-T,
запаянный на NUCLEO-G071RB.

MCO от ST-Link отключен. Это сделано специально: при коммутации силового
транзистора помехи раньше могли приводить к отваливанию ST-Link, а локальный HSE
кварц на плате Nucleo делает тактирование независимым от ST-Link.

## Источник тактирования

```
HSE = 8 MHz

```

Подключение:

| Вывод | Назначение  |
| ----- | ----------- |
| PF0   | RCC_OSC_IN  |
| PF1   | RCC_OSC_OUT |

Параметры PLL:

| Параметр   | Значение |
| ---------- | -------- |
| PLL Source | HSE      |
| PLLM       | 1        |
| PLLN       | 16       |
| PLLR       | 2        |

Расчет:

```text
8 MHz × 16 / 2 = 64 MHz

```

Итоговые частоты:

| Clock  | Value  |
| ------ | ------ |
| SYSCLK | 64 MHz |
| HCLK   | 64 MHz |
| PCLK   | 64 MHz |

```

                                ▼

                                │
                                ▼

```

## Сигнал TORQUE / датчик момента T22

Временная макетная схема входа для датчика момента `HBM/HBK T22 50 Nm`.

Вход STM32:

| Сигнал | Вывод STM32 | Канал ADC |
| ------ | ----------- | --------- |
| TORQUE | PB1 / A3    | ADC1_IN9  |

Масштаб датчика, используемый в прошивке:

```text
T22 50 Nm voltage output: +/-5 V = +/-50 Nm
Sensor scale:              10 Nm/V
```

Питание аналоговой макетки:

```text
LD1117 OUT 3.3V -> MCP6002 pin 8
GND              -> MCP6002 pin 4

LD1117 input:   10 uF + 100 nF to GND
LD1117 output:  10 uF + 100 nF to GND
MCP6002 supply: 100 nF between pin 8 and pin 4
```

ОУ A в `MCP6002` делает опорную середину:

```text
3.3V --10k--+--10k-- GND
            |
          INA+ pin 3

OUTA pin 1 -> INA- pin 2

OUTA = about 1.65 V reference
100 nF from OUTA / 1.65 V point to GND
```

ОУ B буферизует смещенный сигнал датчика момента.
Текущая макетная схема:

```text
T22 signal --100k--+--> INB+ pin 5
                   |
                  33k
                   |
              OUTA 1.65 V

OUTB pin 7 -> INB- pin 6
OUTB pin 7 --100R-- PB1 / A3 / ADC1_IN9
```

Собранный вариант для входного диапазона около `+/-3 V`:

```text
Replace the 33k resistor from INB+ to OUTA/1.65V with 54.9k.
On the breadboard it is built as 51k + 3.9k in series.

T22 signal --100k--+--> INB+ pin 5
                   |
                 51k
                   |
                 3.9k
                   |
              OUTA 1.65 V
```

С резисторами `100k` и `54.9k` (`51k + 3.9k` последовательно):

```text
Vpb1 = (54.9 / (100 + 54.9)) * Vt22 + (100 / (100 + 54.9)) * 1.65

Vt22 = -3 V -> Vpb1 ~= 0.00 V
Vt22 =  0 V -> Vpb1 ~= 1.065 V
Vt22 = +3 V -> Vpb1 ~= 2.13 V

ADC sensitivity ~= 35.44 mV/Nm
```

Примечание: пассивный смещенный делитель не использует весь диапазон ADC
`0..3.3 V` симметрично вокруг `1.65 V`. Для красивого отображения
`+/-3 V` примерно в `0.15..3.15 V` нужен активный сумматор/инвертор на ОУ,
а не только замена одного резистора.

# Режимы работы

## Current Control Mode

Основной режим работы.

Пользователь задает требуемый ток:

```
set_i <mA>

```

После этого PI-регулятор автоматически поддерживает заданное значение тока.
Старая команда `set <mA>` оставлена как синоним.

---

## Torque Control Mode

Режим регулирования момента работает внешним контуром поверх контура тока:

```text
set_m <Nm>
```

Тормоз создает тормозной момент в обе стороны вращения, поэтому контур момента
регулирует модуль измеренного момента:

```text
error = set_M - abs(M_measured)
```

Подписанный момент `M_measured` остается в телеметрии, чтобы видеть направление
вращения/нагрузки, но регулятор использует `abs(M_measured)`.

Параметры внешнего контура:

```text
mkp [value]  - P gain, mA/Nm
mki [value]  - I gain, mA/(Nm*s)
mkd [value]  - D damping, mA/Nm/sample
mmax <Nm>    - max torque setpoint
```

Текущие предварительные дефолты:

```text
mkp = 35
mki = 120
mkd = 0
mmax = 50 Nm
```

Параметры, установленные через консоль, сохраняются в TAMP backup-регистрах:

```text
kp, ki
set_i <mA>
imax, dmax
mkp, mki, mkd
mmax
```

Они восстанавливаются после reset. При полной потере питания сохранятся только
если backup-домен MCU остается запитанным.

# Консоль управления

В проекте включены два UART-порта. Это сделано с заделом под подключение
Raspberry Pi: можно оставить ST-Link VCP для отладки с ПК и параллельно
подключить внешний управляющий контроллер к USART1.

Оба порта работают как одна общая консоль управления:

* команды принимаются с обоих UART;
* ответы на команды идут в тот UART, откуда пришла команда;
* глобальные сообщения и сообщения кнопки могут зеркалиться на оба UART;
* потоковая телеметрия и история команд ведутся независимо для каждого порта.

Параметры подключения:

```
921600 baud
8N1

```

| Порт   | Выводы STM32 | Назначение |
| ------ | ------------ | ---------- |
| USART2 | PA2 / PA3    | ST-Link VCP, терминал на ПК |
| USART1 | PC4 / PC5    | Задел под Raspberry Pi или внешний контроллер |

После подключения отображается:

```
===================================
  BORK Loading Stand BOR0394000
  PI current control @ 10 kHz
===================================

Type 'help'.

```

## Управление током

| Команда | Аргументы | Описание |
| ------- | --------- | -------- |
| `set_i` | `<mA>`    | уставка тока, включает контур тока |
| `set`   | `<mA>`    | синоним `set_i` |

---

## Управление моментом

| Команда | Аргументы | Описание |
| ------- | --------- | -------- |
| `set_m` | `<Nm>`    | уставка момента, включает внешний контур момента поверх контура тока |

Контур момента регулирует `abs(M)`, потому что тормоз создает тормозной момент
одинаково в обе стороны вращения. `set_m` ограничивается параметром `mmax`.

## Коэффициенты регуляторов

Если аргумент не указан, команда просто печатает текущее значение.

| Команда | Аргументы | Описание |

| `mkp`   | `[value]` | P коэффициент внешнего контура момента, `mA/Nm` |
| `mki`   | `[value]` | I коэффициент внешнего контура момента, `mA/(Nm*s)` |
| `mkd`   | `[value]` | D демпфирование внешнего контура момента, `mA/Nm/sample` |

## Ограничения

| Команда | Аргументы  | Описание |
| ------- | ---------- | -------- |
| `imax`  | `<mA>`     | максимум уставки тока и максимум тока, который может запросить контур момента |
| `mmax`  | `<Nm>`     | максимум уставки момента |
| `dmax`  | `<0..100>` | максимум PWM duty, последняя защита силового выхода |

`imax` ограничивает максимальную уставку тока и максимальный ток, который может
запросить внешний контур момента. `dmax` ограничивает максимальный коэффициент
заполнения PWM как последнюю защиту силового выхода.

## Диагностика ADC/PWM

| Команда | Аргументы      | Описание |
| ------- | -------------- | -------- |
| `chan`  | `pa0` / `pb1`  | отладочный выбор отображаемого live-канала; рабочий ADC сканирует PA0+PB1 |

## Телеметрия

| Команда   | Аргументы        | Описание |
| --------- | ---------------- | -------- |
| `stream`  | `on [Hz]`        | общий поток `DATA,...` |
| `stream`  | `off`            | выключить общий поток |
| `stream`  | `m [on] [Hz]`    | поток только момента |
| `stream`  | `m off`          | выключить поток момента |
| `streamA` | `on [Hz]`        | поток только тока в амперах |
| `streamA` | `off`            | выключить поток тока |
| `streamM` | `on [Hz]`        | поток только момента |
| `streamM` | `off`            | выключить поток момента |
| `M`       | -                | напечатать момент один раз |
| `M`       | `[Hz]`           | включить поток момента с частотой `Hz` |
| `M`       | `on [Hz]`        | включить поток момента |
| `M`       | `off`            | выключить поток момента |
| `moment`  | как `M`          | синоним `M` |
| `torque`  | как `M`          | синоним `M` |
| `rate`    | `<ms>`           | задать период активного потока в миллисекундах |

Для `[Hz]` допустим диапазон `1..1000`. В одном терминале активен только один
тип потока: общий, ток или момент. В разных UART-консолях потоки независимы.
`Ctrl+C` или `Ctrl+Z` останавливает поток текущей консоли.

# Формат телеметрии

Общий поток:

```
DATA,<tick_ms>,<set_mA>,<I_mA>,<set_Nm>,<M_Nm>,<duty%>

```

Пример:

```
DATA,100,500,498,10,9,31
DATA,200,500,501,10,10,32
DATA,300,500,500,10,10,32

```

Поток тока `streamA`:

```text
 0.5000 A
```

Поток момента `streamM` / `M <Hz>`:

```text
 12.345 Nm
```

# Калибровка

Команда:

```
cal

```

выполняет повторную калибровку нуля датчика тока ACS724 и нуля датчика момента

Рекомендуется выполнять после включения питания и при отсутствии тока через тормоз.
